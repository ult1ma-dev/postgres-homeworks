# Продвинутый синтаксис. Домашнее задание

### Написание sql-запросов

- Напишите sql-запросы на JOIN и подзапросы в файле `queries.sql`


> **Note**
> <br>
> Писать и проверять запросы можно в pgAdmin, а далее код перенести в .sql-файлы.

### Может пригодиться
> Используйте в выборке `CONCAT(first_name, ' ', last_name)`, чтобы объединить имя и фамилию сотрудника.

> Ключевое слово `AS` в SQL используется для переименования столбцов или таблиц в результате запроса. 
> Например, запрос `SELECT first_name AS имя, last_name AS фамилия FROM employees` вернет таблицу с переименованными столбцами "имя" и "фамилия".

> **Note**
> <br>
> В папке screenshots лежат скриншоты результатов, которые должны получиться по каждому sql-запросу.

## Решение

Все четыре запроса находятся в [queries.sql](queries.sql), под соответствующими
номерами заданий. Используются таблицы схемы `public` базы `northwind`,
созданной в [домашнем задании № 2](../homework-2/README.md).

В первом запросе таблица заказов связывает заказчика, сотрудника и перевозчика.
Повторяющиеся пары заказчика и сотрудника сохраняются: они относятся к разным
заказам. Столбцы названы `customer` и `employee`, как на эталонном скриншоте.

В третьем запросе `LEFT JOIN` находит компании без заказов. Четвёртый запрос
использует подзапрос: из `order_details` выбираются идентификаторы продуктов
в позициях заказа с `quantity = 10`. `DISTINCT` оставляет уникальные названия.

### Запуск

В pgAdmin выберите базу `northwind`, откройте Query Tool и загрузите
`queries.sql`. Для проверки отдельного задания выделите его SQL-запрос целиком
и выполните выделенный фрагмент.

Все запросы можно выполнить из корня репозитория через PowerShell:

```powershell
& 'C:\Program Files\PostgreSQL\18\bin\psql.exe' -X -v ON_ERROR_STOP=1 -h localhost -U postgres -d northwind -f homework-3\queries.sql
```

При подключении введите пароль своего пользователя PostgreSQL. Если база ещё
не заполнена, используйте [скрипт Northwind из ДЗ № 2](../homework-2/northwind_script.sql)
и инструкцию его запуска.

### Проверка

Все четыре запроса выполнены на PostgreSQL 18.6 через `psycopg2`.
Проверены значения, число строк, названия и порядок столбцов. Результаты
сверены с исходными таблицами и скриншотами задания.

| Запрос | Результат |
| --- | --- |
| № 1. Заказчик и сотрудник из London, перевозчик United Package | 5 строк |
| № 2. Активные товары нужных категорий с остатком меньше 25 | 9 строк, остатки от 0 до 24 по возрастанию |
| № 3. Компании без заказов | FISSA Fabrica Inter. Salchichas S.A.; Paris spécialités |
| № 4. Уникальные товары из позиций с количеством 10 | 60 названий |

Во втором запросе проверена сортировка по `units_in_stock`. В остальных
запросах порядок строк не задан через `ORDER BY`, поэтому проверяется состав
результата с учётом повторений.
