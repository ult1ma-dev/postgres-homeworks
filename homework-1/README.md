# Введение в БД. Домашнее задание

### Установка Postgres

- [Скачать](https://www.postgresql.org/download/) и установить локально Postgres

### Создание БД

- Подключиться к Postgres из командной строки
- Создать БД с названием `north`

### Создание таблиц

- Ознакомиться с данными в папке `north_data`
- Создать три таблицы, используя `query tool` в pgAdmin
    - `employees`
    - `customers`
    - `orders`
- Колонки для таблиц и связи между таблицами определить самостоятельно
- Sql-код для создания таблиц скопировать в файл `create_tables.sql`

### Заполнение таблиц данными

- Написать скрипт в `main.py`, который заполнит созданные таблицы данными из `north_data`
- Для подключения к БД использовать библиотеку `psycopg2`
- Зайти в pgAdmin и убедиться, что данные в таблицах есть

## Решение

В `create_tables.sql` описаны все колонки исходных CSV. Первичные ключи:
`employees.employee_id`, `customers.customer_id` и `orders.order_id`.
Внешние ключи `orders.customer_id` и `orders.employee_id` связывают заказы
с клиентами и сотрудниками. Даты хранятся в типе `DATE`, примечания — в `TEXT`.

### Запуск на Windows

Команды выполняются из корня репозитория в PowerShell. Для `psql` и `python`
нужны соответствующие пути в `PATH`. Если PostgreSQL установлен стандартно,
вместо `psql` можно использовать `& 'C:\Program Files\PostgreSQL\18\bin\psql.exe'`.

1. Создайте виртуальное окружение и установите зависимость:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r homework-1\requirements.txt
   ```

   Пакет `psycopg2-binary` предоставляет библиотеку `psycopg2`.

2. Подключитесь к PostgreSQL из командной строки и создайте базу:

   ```powershell
   psql -h localhost -U postgres -d postgres -f homework-1\create_database.sql
   ```

   Введите пароль, заданный при установке PostgreSQL. Если база `north` уже
   создана, повторять этот шаг не нужно.

3. В pgAdmin откройте сервер, выберите `Databases → north`, откройте
   **Query Tool** и выполните содержимое `create_tables.sql`.
   Файл можно выполнить повторно: таблицы создаются с `IF NOT EXISTS`.

4. Запустите загрузку данных:

   ```powershell
   .\.venv\Scripts\python.exe homework-1\main.py
   ```

   Скрипт запросит пароль. По умолчанию используется `localhost:5432`, база
   `north`, пользователь `postgres`. Параметры можно задать переменными
   окружения `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`.

   Ожидаемый вывод:

   ```text
   employees: загружено 9 строк
   customers: загружено 91 строк
   orders: загружено 830 строк
   ```

5. В Query Tool pgAdmin выполните `verify.sql`. Первый запрос покажет число
   записей, второй — примеры заказов с клиентами и сотрудниками,
   третий — отсутствие заказов с нарушенными связями.

`main.py` читает CSV через `csv.DictReader`, сохраняет кириллицу и другие
символы Unicode и передаёт значения в SQL параметрами. Сначала загружаются
сотрудники и клиенты, затем заказы. Все изменения выполняются одной
транзакцией. Повторный запуск обновляет записи с теми же ключами через
`ON CONFLICT DO UPDATE`, поэтому дубликаты не появляются.

### Проверка решения

Проверено на PostgreSQL 18.6, Python 3.14.6 и psycopg2 2.9.11:

- Все значения в 930 строках трёх таблиц совпали с исходными CSV.
- Повторная загрузка сохранила количество строк и их содержимое.
- Заказ с несуществующим сотрудником был отклонён внешним ключом.
- После этой ошибки изменения предыдущих таблиц откатились целиком.
